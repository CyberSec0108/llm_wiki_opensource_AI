## 한 줄 요약
내가 누구이고 왜 이 위키를 운영하는지 — AI가 내 맥락에 맞춰 답하기 위한 배경 파일.

> [!note] 갱신 주기
> 분기 1회 권장. 자주 바뀌는 단기 목표나 현재 작업은 [[지금 하는 일]]에 씁니다.

## 1. 나는 누구인가

- **하는 일**: (예: 보안과 AI를 함께 공부하는 연구자 / 소프트웨어 엔지니어 / 데이터 분석가)
  
  연구 또는 학습 축을 **두세 가지**로 정의합니다. 자료를 수집·정리할 때 이 축에 속하는지 먼저 판단합니다.

  | 축 | 내용 | 태그 |
  |---|---|---|
  | **축 1 (예: AI로 보안을)** | AI를 활용해 보안 업무나 분석을 자동화하는 방법 | `#ai-for-security` |
  | **축 2 (예: 보안으로 AI를)** | AI 모델과 시스템 자체의 안전성을 지키는 것 | `#securing-ai` |

  정의된 축에 해당하지 않는 자료는 수집 우선순위를 낮춥니다.

- **강점**: (예: 체계적인 계획 수립, 논문/기술 아티클 분석, 구현 능력)
- **일하는 방식**: (예: 복수 자료를 교차 검토하여 공통점과 차이점을 비교 분석)

## 2. 왜 기록하고 싶은가

- **지금 겪는 문제**: (예: 읽은 자료가 흩어져 있고, 시간이 지나면 다시 찾기 어려움)
- **해결하고 싶은 목표**: (예: 파편화된 지식을 하나의 위키로 연결하고 체계화하는 것)
- **1년 후의 모습**: (예: 나만의 전문 연구 노트이자 논문/아티클의 든든한 기반)

## 3. 어떤 아웃풋을 만들고 싶은가

- **대상 독자**: (예: 초·중급 보안/AI 개발자 및 연구자)
- **결과물의 형태**: (예: 사내 기술 블로그, 세미나 발표 자료, 논문 초안)
- **성공 기준**:
  - 쉽게 이해될 것 (`## 한 줄 요약` 필수)
  - 쉽게 찾아질 것 (`aliases`, `index.md` 등록)
  - 중복이 없을 것 (기존 페이지 우선 갱신)
  - 상호 연결될 것 (최소 2개 이상의 백링크)
