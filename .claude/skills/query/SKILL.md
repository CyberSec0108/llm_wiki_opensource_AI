# query — 위키를 근거로 답하기

답변 규칙은 `context/나의 핵심 맥락.md`의 "4. AI 작업 규칙"을 따른다. 여기에 중복해 적지 않는다.
핵심만: **개념부터 상세히 / 비교 예시 필수 / 단일 출처로 결론 내지 않기.**

## 1. index부터 읽는다

`wiki/index.md`를 먼저 읽어 후보를 좁힌다. **위키 전체를 읽지 마라.** index가 그 비용을 줄이려고 있는 것이다.

질문이 어느 축인지 먼저 판단하면 후보가 절반으로 준다.

| 축 | 입구 |
|---|---|
| AI로 보안을 | [[AI 활용 보안 자동화]] |
| AI를 지킨다 | [[AI 시스템 보안]] |

축이 애매하면 양쪽 MOC를 모두 본다.

## 2. 후보 페이지만 읽고 답한다

- 근거가 된 페이지를 **반드시 `[[링크]]`로 밝힌다.** 어느 문장이 어느 페이지에서 왔는지 알 수 있어야 한다.
- 링크를 걸었으면 그 페이지를 **실제로 읽었어야 한다.** 제목만 보고 인용하지 마라.

### status에 따라 인용 강도를 바꾼다

| status | 인용 방식 |
|---|---|
| `stable` | 근거로 자유롭게 인용 |
| `draft` | 인용하되 **"검증 필요"를 명시** |
| `seed` | 참고만. **근거로 인용 금지** |

`source`가 2개 이상인 서술은 "출처 2개로 교차 확인됨"이라고 밝힌다. 1개뿐이면 그것도 밝힌다.

## 3. 위키에 없으면 명확히 말한다

**"위키에 없음"이라고 먼저 명시**한 뒤 일반 지식으로 답한다. 위키에서 읽은 것처럼 섞지 마라.
이 구분이 무너지면 위키의 신뢰도 전체가 무너진다.

그 다음 순서로 보강한다.

1. `wiki/` 안에서 다른 표현으로 재검색 — 한국어·영어·약어, `aliases`까지
2. **그래도 없으면** `raw/`를 검색한다. raw는 최후 수단이다 (양이 많고 정리돼 있지 않다)
3. raw에도 없으면 "이 볼트에 근거가 없다"고 말하고, 어떤 자료를 수집하면 좋을지 제안한다

## 4. Knowledge Flywheel — 답변을 위키로 되먹이기

좋은 답변이 나왔으면 위키에 남긴다. **질문이 위키를 풍요롭게 만드는 순환**이다.

단, 아무 답변이나 저장하면 위키가 대화 로그가 된다. 아래 조건을 지킨다.

### 저장할 가치가 있는가

| 저장한다 | 저장하지 않는다 |
|---|---|
| 여러 페이지를 종합해 **새로운 연결**을 만들었다 | 한 페이지 내용을 그대로 옮겼다 |
| 위키에 없던 개념을 정리했다 | 단순 사실 확인 |
| 비교·정리 표를 새로 만들었다 | 일회성 판단 |

### 저장한다면

1. **기존 페이지 갱신이 새 페이지 생성보다 우선한다.** `wiki/CLAUDE.md`의 "새 페이지를 만들기 전에" 절차를 그대로 따른다
2. **저장 전에 사용자에게 확인받는다.** 무엇을, 어디에, 왜 저장할지 먼저 말한다
3. 위키에서 파생된 페이지는 **출처가 raw가 아니라 wiki다.** 이를 frontmatter에 드러낸다

```yaml
source:
  - wiki/에이전틱 AI.md        # 파생 출처는 wiki 경로로
  - wiki/프롬프트 인젝션.md
derived: true                  # 원본이 아니라 위키에서 파생됐음
status: draft                  # 파생 페이지는 draft를 넘지 않는다
```

`derived: true`인 페이지를 **다시 근거로 삼아 또 파생시키지 마라.** 원본에서 멀어질수록 오류가 누적된다.

## 5. 마무리

저장했을 때만 수행한다.

1. `wiki/index.md`에 한 줄 추가 — 120자 이내
2. `wiki/log.md`에 append — 연산을 `query`로 적고, **어떤 질문에서 나왔는지** 남긴다
3. 새 페이지를 만들었으면 **왜 기존 페이지에 못 넣었는지** 함께 적는다

## 하지 말 것

- 위키 전체를 읽고 시작하기 — index를 쓰라고 만든 것이다
- 근거 없이 `[[링크]]`만 걸기
- `seed` 페이지를 근거로 단정하기
- 위키에 없는 내용을 있는 것처럼 섞기
- 확인 없이 위키에 저장하기
- `derived: true` 페이지를 근거로 또 파생 페이지 만들기
